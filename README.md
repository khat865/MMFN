# MMFN Project Website

This repository hosts the public project website for **Can Multimodal Large Language Models Generate and Detect Multimodal Social Media Fake News?**

- [Project website](https://khat865.github.io/MMFN/)
- [Paper-linked project hub](https://github.com/xiuzhenzhang/Multimodal)
- [Request data and code access](https://huggingface.co/datasets/Khat865/Mutilmodel_fake_news)

The website repository contains only static presentation files and the manuscript PDF. Benchmark data, construction code, evaluation code, and prompts are distributed separately through the gated Hugging Face repository.
