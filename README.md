# MMFN Project Website

This repository hosts the public project website for **Can Multimodal Large Language Models Generate and Detect Multimodal Social Media Fake News?**

- [Project website](https://khat865.github.io/MMFN/)
- [Paper-linked project hub](https://github.com/xiuzhenzhang/Multimodal)
- [Access conditions and application instructions](https://khat865.github.io/MMFN/#access)
- [Request access on Hugging Face](https://huggingface.co/datasets/Khat865/Mutilmodel_fake_news)

This is the single public project website. It combines the paper overview, access conditions, release scope, and application instructions on one page. The paper-linked GitHub repository is a README-only entry point, not a second project website. The site does not display dataset examples or host a separate application form.

The website repository contains only static presentation files and the manuscript PDF. Synthetic research data, construction code, evaluation code, and prompts are distributed through the manually approved Hugging Face repository. Original true-news articles, original source images, and true-post texts, including embedded copies in construction artifacts, are excluded from that release.

Applicants provide their name, university or institution, institutional email, a public university profile or ORCID, and a short statement of intended research use. Reviewers check identity and affiliation manually; collecting those fields is not identity verification. One approved account receives access to the released resources, and collaborators apply separately.

Use is restricted to the approved non-commercial academic, educational, or scientific research purpose. Commercial use, including product development, commercial services, internal business operations, and third-party monetization, is prohibited. Code, data, derived unencrypted subsets, archives, and access credentials must not be redistributed, mirrored, hosted, or transferred to third parties or external platforms.

Contact for applications, affiliation checks, and security reports: `xiuzhen.zhang@rmit.edu.au`.

The synthetic-only release cannot by itself reproduce the paper's full true/fake evaluation. Exact reproduction requires the original inputs and evaluation protocol; source URLs do not guarantee reconstruction of withheld true-post texts. Results on the released subset must be reported as subset results.
